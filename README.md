# LOKANATH FITNESS

A static fitness affiliate product discovery website built with HTML, CSS and vanilla JavaScript. It can be hosted free on GitHub Pages.

## Files
- `index.html` — homepage, categories, product search and filters
- `style.css` — responsive black, white and orange design
- `products.js` — sample product catalogue
- `script.js` — product rendering, search, filters and mobile navigation
- `about.html`, `contact.html`, `privacy.html`, `terms.html`, `affiliate-disclosure.html` — supporting pages

## Run locally
Open `index.html` in a browser. For best results, use a local static server or VS Code Live Server.

## Publish with GitHub Pages
1. Create a GitHub repository named `lokanath-fitness` (public).
2. Upload all files in this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for deployment. Your site URL will look like `https://YOUR-USERNAME.github.io/lokanath-fitness/`.

## Before launch — important
1. Apply for the relevant affiliate programmes and confirm current eligibility and rules.
2. Replace every placeholder `affiliateUrl` in `products.js` with a valid affiliate tracking URL generated by the programme. The current links go only to generic retailer homepages and do not track commissions.
3. Replace sample product data with accurate product names, descriptions, prices and permitted images. The sample images are remote Unsplash images and are illustrative, not images of the actual listed products.
4. Replace the placeholder email in `contact.html`.
5. Add the exact Amazon Associates disclosure required by the current programme agreement if you are approved.
6. Check local legal, tax, consumer-protection and programme requirements before monetizing.

## Editing products
Edit the `products` array in `products.js`. Each object uses:
`id`, `name`, `category`, `description`, `price`, `merchant`, `image`, `affiliateUrl`.

Allowed category values used by the filters: `Clothing`, `Accessories`, `Equipment`, `Bottles`.
Allowed merchant values used by the filters: `Amazon India`, `Flipkart`.

This is a static catalogue. It has no secure admin dashboard, database, checkout, inventory or payment processing. Product updates are made by editing `products.js` and uploading the changed file to GitHub.
